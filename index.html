NAS Backups

Encrypted cloud backups for a personal network storage server.

NAS Backups is a personal-use tool operated by Trevor Morgan. It uses rclone and Restic to copy data to Google Drive, check the stored backups, and support recovery.

How it uses Google Drive

  • Reads Drive files and folders for configured synchronization and backup verification.
  • Creates and maintains backup files in the account owner’s Drive.
  • Encrypts NAS backup content before uploading it.

It is intended for the owner’s accounts and storage. Access requires the Google account owner’s authorization.

Read the privacy notice for details about data use and access controls.
